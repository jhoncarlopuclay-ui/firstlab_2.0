# Student Information CRUD System

A responsive student directory built with React, Vite, and Supabase. The interface includes student creation, search by student number or name, program and year filters, editing, and confirmed deletion. Without Supabase environment variables, the app runs as a local preview and persists changes in browser storage.

## Run locally

1. Install Node.js 18 or later.
2. Run `npm install` and `npm run dev`.
3. Open the local URL printed by Vite.

## Connect Supabase

Copy `.env.example` to `.env.local`, then add your Supabase project URL and anon key. The app uses the `students` table and selects records by newest first. Create the table in your Supabase SQL Editor:

```sql
create table public.students (
  id bigint generated by default as identity primary key,
  student_id text not null unique,
  first_name text not null,
  last_name text not null,
  program text not null,
  year_level integer not null check (year_level between 1 and 4),
  email text not null,
  created_at timestamptz not null default now()
);

alter table public.students enable row level security;
create policy "Public student access" on public.students
  for all using (true) with check (true);
```

The sample policy allows public access for a classroom demo. For real student information, configure Supabase Auth and limit table access with appropriate Row Level Security policies before deployment.

## Deploy to Vercel

Import this repository into Vercel, set `VITE_SUPABASE_URL` and `VITE_SUPABASE_ANON_KEY` in project environment variables, and deploy. Vite is detected automatically.
